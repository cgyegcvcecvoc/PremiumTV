PremiumTV 1.1.x Encore preview — retired

This preview is retired.
Install stable 1.1.3 instead.

The old 1.1.x Encore preview channel is gone: its release, installers and download links were removed, and every retired-preview link this project still controls points here. Nothing on this page installs a preview.

PremiumTV 1.1.3 is the current stable release — Android 1.1.3 (versionCode 101030000) and macOS 1.1.3. It recovers silent broadcast audio (AC-3/E-AC-3/MP2 and HLS audio renditions), adds a moving gold startup loading bar, expands Movies & Shows to 21 verified public-domain classics with built-in player transport controls, and keeps the docked side player, category rail, automatic server backup, dead-channel filtering and checksum-verified in-app updates.

Note: 1.1.0, 1.1.1 and 1.1.2 are ordinary stable releases, not blocked builds. The deleted preview once shared those numbers; the project promoted the names back, so a device on any of them is on a supported build — it just updates to 1.1.3 in Settings → App updates.
