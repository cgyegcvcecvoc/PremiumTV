Download the apps

The channels and guide ship inside the app — nothing to configure. Android installs on Android TV, Google TV, Fire TV, tablets and phones; the macOS build runs on Intel and Apple Silicon.

Older releases

    Android TV / Fire TV

    1. Download the .apk on the device (or copy it over USB / a file app).
    2. Open it and allow installs from unknown sources when asked.
    3. Fire TV: use Downloader or a file manager to open the APK, then allow it.

    macOS

    1. Download the .dmg (drag to Applications) or .pkg (installer).
    2. Builds are ad-hoc signed: first launch may need right-click → Open.
    3. Or run: xattr -d com.apple.quarantine /Applications/PremiumTV.app

    Verify your download

    Every release ships SHA256SUMS files. Check yours:

    sha256sum PremiumTV-*.apk

    macOS: shasum -a 256 <file>

      Help

      How do I load an M3U playlist?

      Copy the playlist URL above, then in your player: VLC → Media → Open Network Stream; TiviMate / IPTV Smarters → add playlist → M3U URL; Kodi → PVR IPTV Simple Client → Remote path. Paste the URL, save, and the channels appear.

      Which playlist is “the best working one” for my country?

      The country playlist shown above: it contains only links the last checks confirmed working, split out of the main library, and its header points your player at that country’s own guide (EPG/<Country>.xml). Want everything? Use PremiumTV.m3u from the quick picks.

      Why do channels sometimes disappear and come back?

      Public streams move around. Our runs check every link several times a day: confirmed-dead links are removed (or held in quarantine), links that merely timed out are kept and retried, and channels that come back are republished automatically. The change log records what happened.

      App or playlist — which should I use?

      The apps bundle the lineup and guide inside the APK/.dmg, add a TV remote interface, a cable-style program guide and automatic refresh. Playlists suit any player you already own. Both read the same checked channel library.

      Is this legal?

      The library only links streams that publishers already list publicly on the internet. Availability depends on the source and your region; we don’t host or re-broadcast anything.
