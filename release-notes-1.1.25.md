# PremiumTV 1.1.25 — Spotify on every screen

Android `1.1.25` / versionCode `101250000` · macOS `1.1.25`.

- A Spotify tab in the web, macOS, Linux and Android TV apps: playlists, albums and podcasts.
- Sign-in uses PKCE and stores nothing on a server; the tab plays Spotify's own player.
- Free accounts hear Spotify's ads: the tab says so and blocks, mutes or skips nothing.
- In-app streaming uses Spotify's Web Playback SDK, which Spotify limits to Premium.
- Open in Spotify, your own links and the redirect URI are one tap away.
