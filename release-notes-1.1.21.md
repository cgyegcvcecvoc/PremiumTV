# PremiumTV 1.1.21 — Free provider directory

Android `1.1.21` / versionCode `101210000` · macOS `1.1.21`.

- M3UPT, TDTChannels and Nexonic IPTV join the sources: Portuguese and Spanish public TV, 160 countries.
- A source can declare which upstream groups it contributes, so a mixed file adds only its TV half.
- Grade TV, Broadcast Atlas and Open TV Atlas are checked as references; all three re-publish iptv-org.
- The new provider audit measures every free listing in the awesome-iptv directory against this corpus.
- A country playlist header can no longer advertise every source's guides, so the scrape gate passes.
