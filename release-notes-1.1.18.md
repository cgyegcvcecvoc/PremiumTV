# PremiumTV 1.1.18 — Linux desktops and location access

Android `1.1.18` / versionCode `101180000` · macOS `1.1.18`.

- PremiumTV now builds for Linux desktops: AppImage, .deb and tar.xz for x86-64 and arm64.
- macOS asks for location access again: the app ships the privacy usage string it was missing.
- Android asks the runtime permission, then waits up to 8s for a real fix instead of an empty cache.
- A nearest market that is out of range is now named with its distance, never applied silently.
- Two new channel sources, aria+ and Pluto TV US, arrive with their own programme guides.
