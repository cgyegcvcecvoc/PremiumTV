🧭 Directions — pick your device

Honest, step-by-step. Each takes about two minutes.

🔥 Fire TV Stick / Fire TV
  1. On the Fire TV: Settings → My Fire TV → Developer Options → Install unknown apps → turn it on for Downloader. (If Developer Options is hidden: Settings → My Fire TV → About → click your device name 7 times.)
  2. Install the free Downloader app from the Amazon Appstore and open it.
  3. Type this hub's address followed by the APK path shown on the Android card above (or use the short link the card shows), then press Go.
  4. When the APK finishes downloading, choose Install, then Open.
  5. Done — PremiumTV ships with its playlist and guide built in. It refreshes them automatically.
📺 Android TV / Google TV
  1. Allow installs from unknown sources: Settings → Apps → Security & restrictions → Unknown sources (wording varies by TV) and enable it for your browser or file manager.
  2. Download the APK from the Apps section using the TV's browser — or download it on your phone/PC and move it over with Send Files to TV or a USB stick.
  3. Open the APK from the notification or a file manager and choose Install.
  4. Launch PremiumTV. The lineup and guide are built in and auto-refresh.
🍏 macOS
  1. From the Apps section download the DMG (drag-and-drop) or PKG (guided installer) for your Mac — Apple Silicon for M-series, Intel for older Macs.
  2. DMG: open it and drag PremiumTV into Applications. PKG: double-click and follow the prompts.
  3. First launch: right-click the app → Open → Open (the build isn't notarized with Apple, so macOS asks once).
  4. That's it — channels and guide are bundled and refresh on their own.
🎬 VLC (Windows / Mac / Linux / phone)
  1. Easiest: download any .m3u from this page and double-click it — VLC opens it as a channel list.
  2. Or stay always-up-to-date: in VLC choose Media → Open Network Stream (⌘N / Ctrl+N), paste a playlist's Copy URL link, and press Play.
  3. Browse channels via View → Playlist (Ctrl+L).
📡 TiviMate / IPTV Smarters / OTT Navigator
  1. Add a playlist: choose M3U Playlist → URL, and paste the Copy URL link of the playlist you want (main, your country, or a category).
  2. The guide usually configures itself — these playlists advertise their guide URL in the M3U header. If your app asks for an EPG URL, paste the Copy URL link from the TV guide section (use the .xml.gz one if supported — it's 10× smaller).
  3. Set playlist auto-update to daily; the library is re-checked and republished every day.
🟦 Kodi (PVR IPTV Simple Client)
  1. Install PVR IPTV Simple Client: Add-ons → Install from repository → PVR clients.
  2. Configure it: General → Location: Remote path, and paste a playlist's Copy URL link as the M3U URL.
  3. Under EPG, paste the guide URL from the TV guide section.
  4. Enable the client and restart Kodi — channels appear under TV.
Which link do I give my player? Use the Copy URL buttons. Those links point at the project's public raw-file storage, update automatically every day, and keep working forever — perfect for players that re-download the playlist on a schedule. The Download buttons give you the same file as a one-time copy from this hub.

🙋 About us

What PremiumTV is

PremiumTV is a small, independent project that collects publicly listed, free-to-watch TV streams from around the web and turns the mess into something you'd actually use: clean playlists, a real TV guide, and native apps for the living room.

Every day an automated pipeline pulls from dozens of public sources, removes duplicates, and actually connects to every single stream to see if it plays. Only links that pass make it into the playlists on this page. Dead links are retired automatically, new ones are hunted monthly, and every run is logged publicly.

What we believe

  • Proof over promises. "11,000 channels" means 11,000 links a machine verified today — the run reports are public.
  • No gatekeeping. No accounts, no trackers, no paywall, no "premium tier". Premium is the quality bar, not a price.
  • Bring your own player. Our apps are the easy path, but every playlist works in any M3U player you already love.

The legal bit

PremiumTV hosts no video. The playlists are catalogs of stream URLs that broadcasters and aggregators have published openly on the internet — the same links any search engine can find. Availability is up to each broadcaster; if a stream owner wants a link removed, removing it from the public source removes it from the next day's run.

Get in touch / dig deeper

The whole pipeline — scraper, checkers, guide builder, app source — is open at github.com/cgyegcvcecvoc/PremiumTV1. Found a dead channel or want one added? Open an issue there and the next run will pick it up.
