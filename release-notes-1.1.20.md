# PremiumTV 1.1.20 — Many sources, one clock

Android `1.1.20` / versionCode `101200000` · macOS `1.1.20`.

- Seventeen backup addresses across eight sources keep a channel playing when one host is down.
- Live Events gains a ticking clock; every kickoff on the tab is read in its zone.
- The clock starts from your saved market's zone and can be switched, remembered per device.
- xyzstreams, ppv.st and Easy-Web-TV are checked as references; none publishes a static playlist.
- The browser build ships the same clock, so web, Mac, Linux and Android agree.
