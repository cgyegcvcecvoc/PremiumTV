- EPG coverage counts the `tvg-id` values the advertised local guide declares. A channel without a public schedule counts as uncovered; its ID is still declared so a player asks for it instead of guessing.
- The `categories/` shelf (headline file `categories/USA.m3u`) is written by `scripts/build_categories.py` and checked here against the published playlists, so its sorting cannot drift from theirs.
